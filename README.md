# 📅 SyncDesk — Agenda Digital para Profissionais

> 📚 Projeto Integrador — Centro Universitário da Fundação Educacional de Barretos (UNIFEB)  
> Curso: Sistemas de Informação  
> Autores: Alex Nascimento Solera; Caique da Silva Alves; Haniel Luiz da Silva; Lucas Rodrigues de Lima

 ## 🧠 Sobre o Projeto

Este software foi desenvolvido como parte do **Projeto Integrador** do curso de **Sistemas de Informação** do **Centro Universitário da Fundação Educacional de Barretos (UNIFEB)**.

O objetivo é aplicar os conhecimentos adquiridos ao longo do curso em um sistema real e funcional.

## 📌 Funcionalidades Principais

- ✅ **Login com autenticação de usuários**
- 👤 **Cadastro de clientes com CPF**
- 📆 **Agendamento de horários e tarefas**
- 💰 **Controle financeiro**: entradas, saídas e saldo
- 📊 **Dashboard** com gráfico de movimentação
- 📎 **Geração de relatórios semanais em PDF**
- 🔔 **Notificações do Windows** para tarefas futuras
- 🛠️ **Sistema de permissões** por tipo de usuário (`admin` e `user`)

- ## 🧑‍💻 Tecnologias Utilizadas

| Tecnologia    | Descrição                            |
|---------------|--------------------------------------|
| C# / WinForms | Interface e lógica da aplicação      |
| PostgreSQL    | Banco de dados relacional            |
| Npgsql        | Conector PostgreSQL para C#          |
| iTextSharp    | Geração de PDFs                      |
| System Tray   | Notificações nativas do Windows      |
